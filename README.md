# csv-cleaner

Чистка CSV с контактами (name, phone, email) на Python. Без внешних зависимостей.

## Что делает
- обрезает пробелы в именах;
- приводит российские телефоны к виду `+7XXXXXXXXXX` (понимает 8, +7 и 10 цифр);
- переводит email в нижний регистр и проверяет формат;
- убирает дубли по email или телефону;
- плохие строки (пустое имя, неверный телефон или email, дубли) пишет в отдельный файл.

## Запуск
```
python csv_cleaner.py contacts.csv clean.csv rejected.csv
```
